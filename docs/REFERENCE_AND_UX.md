# KOS JEANS — функциональный референс и UX-решения

Дата исследования: **2026-11-24**, Europe/Vienna. Блок 03.
Референс изучен как действующий публичный сайт, без заказов и авторизации.

## Что действительно проверено

| Источник | Проверено | Наблюдение |
| --- | --- | --- |
| [Главная Spazio](https://spazio.ua/) | HTML, desktop в Chrome, мобильная эмуляция 390×844 | Верхняя навигация по аудиториям, поиск и служебные иконки; крупные кампании и товарные подборки |
| [Женский раздел](https://spazio.ua/ua/zhenshchinam/) | Публичный HTML | Группировка ассортимента по типу одежды и брендам, вложенная таксономия |
| [Джинсы](https://spazio.ua/ua/zhenshchinam/odezhda/dzhinsy/) | Chrome: desktop и mobile, фильтр и сортировка открыты | Desktop: фильтры слева, три товарные колонки в проверенном окне; mobile: две колонки и отдельные кнопки фильтра/сортировки |
| [Товар](https://spazio.ua/ua/zhenshchinam/odezhda/dzhinsy/dzhinsy_017146511_unisex/) | Chrome: mobile и desktop, структура страницы | Несколько фото, цена, выбор размера, таблица размеров, описание/состав/код, связанные товары |

На мобильном главная → меню → «Одяг» → «Джинси» пройдены вручную.
Меню раскрывает вложенные уровни; в фильтре видны магазин, бренд, цвет и размер.
Проверенная сортировка: новинки, цена по возрастанию и по убыванию.
В карточках есть фото, название, бренд, цена, отдельные отметки новизны и скидки;
внизу каталога — дополнительная загрузка и номера страниц.
Варианты размера товара содержат информацию об ограниченном наличии.

Ограничения: web-fetch категории вернул 403, но обычный Chrome открыл её;
выводы по категории получены из браузера. Реальные покупки, корректность
остатков, серверная сортировка и механика заказов не проверялись. Поведение
desktop-меню по hover не тестировалось; вложенность проверена на mobile.
Большое уведомление о cookie перекрывает часть мобильного экрана — это
наблюдение о конкретной сессии, а не результат полного аудита доступности.

Ниже — решения для будущей реализации, а не утверждения о возможностях Spazio
или о уже работающих функциях KOS JEANS.

| --- | --- | --- |

| Динамические категории | Компонент принимает дерево из данных. UUID/id — ключ; slug — адрес. Порядок, видимость и вложенность приходят с сервера | 05–06, управление 09 |

| Каталог | Заголовок и количество над товарами; desktop 4 колонки, mobile 2. 3:4 кадр и одинаковая область подписи; без тесных белых карточек с тенями | 06 |
| Фильтры | Размер, цвет, цена, наличие и категория. Выбранные условия видны; есть сброс; состояние в URL. Mobile-панель с результатом и явным применением | 06 |

| Страница товара | Desktop: галерея и информационная колонка. Mobile: галерея перед названием/ценой/размером. Важное действие не скрывать под длинным описанием | 07 |
| Варианты | Размеры видимыми контролами, недоступные отключены. Цвет+размер однозначно определяют variant. Подпись причины недоступности | 07, 11 |

### Контракт динамического меню

Планируемый UI-контракт, не схема БД:

```ts
type NavigationNode = {
  id: string;
  label: string;
  href: string;
  children: NavigationNode[];
};
```

Сервер отбирает доступные категории, строит ссылки по slug и сортирует дерево.
Компоненты не содержат собственных массивов «Жінкам → Джинси», не используют
имя/slug как неизменяемый идентификатор. Скрытие родителя скрывает его ветвь в
публичном меню; архивирование не удаляет связанные товары. Циклы и права
редактирования проверяются в соответствующих блоках БД и админки.

## Визуальная концепция

**«Характер у деталях»**: спокойная модульная композиция, заметный размер
типографики и деним как редкий цветовой акцент. Чёрный wordmark KOS JEANS,
белый фон, графитовый вторичный текст, тонкие разделители и прямые углы.
Свободное место используется для иерархии, а не для декоративных карточек.
Образ бренда строится вокруг посадки и силуэта, а не вокруг логотипов других марок.

В `/design-system` показаны собственные векторные исследования формы и
демонстрационные цены в UAH. Это библиотека образцов, не главная магазина
и не опубликованный ассортимент. Все иллюстрации написаны специально для
проекта. Фотографии, логотипы, рекламные тексты, исходный код и уникальные
композиции Spazio в проект не переносились.

Правила токенов, сетки, состояний и компонентов: [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md).
