# Дизайн-система KOS JEANS 01.0

Дата: 2026-11-24. Блок 03. Живая библиотека: `/design-system`.
Интерфейс на украинском; деньги в UAH. Это основа для блоков магазина,
а не реализация главной, каталога, корзины или админки.

## Источник токенов

`src/styles/tokens.css` содержит Tailwind v4 theme и доступные CSS-переменные.
Использовать семантические имена (`text-muted`, `bg-denim`, `border-control`),
а не случайные оттенки в каждом компоненте. Основные цвета:

| Токен | Значение | Применение |
| --- | --- | --- |
| paper | #FFFFFF | Основной фон, текст на тёмном |
| ink | #18191B | Основной текст, главная кнопка |
| graphite | #45484C | Насыщенный вторичный оттенок, hover |
| muted | #62666C | Пояснения, подписи, старая цена |
| canvas | #F4F4F1 | Нейтральный фон фотокадра и технических образцов |
| line | #D6D8DB | Декоративные разделители, не единственная граница поля |
| control | #858B92 | Границы полей и невыбранных контролов |
| denim | #38566F | Акцент, focus-ring, действия второго уровня |
| denim-dark | #243E54 | Насыщенная поверхность, hover denim |
| denim-wash | #EDF2F6 | Спокойный фон акцентных меток |
| danger | #9C302A | Ошибка + текстовое пояснение |
| positive | #326248 | Подтверждение + текст/иконка |

Основной и вспомогательный текст должны иметь контраст не ниже 4.5:1,
крупный текст и видимые границы интерактивных элементов — не ниже 3:1.
Светлый `line` служит разделителем; граница input использует `control`.
Disabled-элементы отличаются и стилем, и нативным состоянием; цвет не несёт
единственную информацию. Белый полупрозрачный декоративный контур не является
интерактивным контролом.

## Типографика

Manrope Variable, веса 400/500/600/700/800, лицензия OFL-1.1. Пакет
`@fontsource-variable/manrope@5.3.0`, включая кириллицу; файлы отдаются самим
приложением, внешнего запроса к Google Fonts при сборке или посещении нет.
Fallback: Arial, sans-serif. Лицензия сохранена в пакете.

| Роль | Размер | Межстрочный | Использование |
| --- | --- | --- | --- |
| display | clamp(48 px, 7vw, 104 px) | 0.98 | Короткая брендовая фраза, максимум 2–3 строки |
| heading | clamp(32 px, 3.6vw, 56 px) | 1.08 | Заголовок страницы/раздела |
| title | clamp(24 px, 2.5vw, 32 px) | 1.2 | Заголовки групп |
| body | 16 px | 28 px | Описания, поля, основные тексты |
| UI/price | 14 px | 20–24 px | Контролы, карточки, цены |
| caption | 12 px | 20–24 px | Пояснения, хлебные крошки |
| eyebrow | 10–11 px | 16 px | Короткая надпись в верхнем регистре, не длинные тексты |

Короткие крупные заголовки имеют отрицательный трекинг; большие абзацы — обычный.
Не уменьшать основной текст ради помещения длинной фразы. Проверять Ґ/Є/І/Ї,
апостроф и ₴. У цен — tabular-nums, у технических подписей — системный monospace.

## Сетка и адаптивность

- Базовый шаг 4 px: 4, 8, 12, 16, 24, 32, 48, 64, 96.
- Контейнер до 1440 px. Поля: `clamp(20 px, 4vw, 64 px)`.
- Между секциями: `clamp(56 px, 7vw, 112 px)`.
- Контент строится на 12 колонках desktop, 6 tablet, 4 mobile; это правило
  композиции, а не обязательный CSS-grid для каждого примитива.
- Breakpoints Tailwind: 640 / 768 / 1024 / 1280 px. До 768 px крупные
  разделённые композиции переходят в один поток; пары образцов остаются 2-up.
- Будущий каталог: 2 товара до 768 px, 3 от 768 px, 4 от 1280 px;
  фильтры выносятся в панель до 1024 px. В библиотеке показана только пара карточек.
- Фотокадр карточки 3:4; обложки одной коллекции одинаковы по масштабу.
  Не обрезать важные части одежды. Для будущей галереи сохранять исходное фото.
- Основное действие 48 px по высоте, минимальная цель касания 44×44 px;
  кнопки/размеры в библиотеке 48 px. На узком экране — перенос, не уменьшение цели.
- Проверять 320, 390, 768 и 1440 px, длинные названия, масштабирование текста
  и отсутствие горизонтального переполнения.

## Компоненты и контракты

| Компонент | Файл | Правило |
| --- | --- | --- |
| Button | `src/components/ui/button.tsx` | primary / secondary / denim; type=button по умолчанию, нативный disabled |
| TextField | `src/components/ui/text-field.tsx` | Обязательные id/label; hint/error связаны через aria-describedby; ошибка aria-invalid |
| SizeSelector | `src/components/ui/size-selector.tsx` | Контролируемое значение, варианты через props; fieldset/legend и radio; стрелки/Tab нативные |
| Badge | `src/components/ui/badge.tsx` | neutral / denim / sale; текст обязателен, не интерактивен |
| Price | `src/components/ui/price.tsx` | Целые копейки; uk-UA/UAH; previous показывается лишь выше текущей цены |
| Breadcrumbs | `src/components/ui/breadcrumbs.tsx` | Массив label/href, текущая страница aria-current; никаких встроенных категорий |
| Accordion | `src/components/ui/accordion.tsx` | Нативные details/summary, открывается Enter/Space, работает без JS |

Не ставить ссылки без адреса и кнопки без действия. Loading для будущих
асинхронных кнопок использует aria-busy и подпись, сохраняет ширину/высоту.
Hover — смена цвета, без скачка размеров; focus-visible — кольцо denim 2 px
с отступом 3 px. Ошибка сопровождается текстом; skeleton имеет фиксированные
пропорции; пустое состояние объясняет отсутствие данных и предлагает реальное
доступное действие. Движение ограничено короткой сменой цвета, с поддержкой
prefers-reduced-motion.

В библиотеке кнопки изменяют только локальное сообщение, выбор размеров
ограничен доступными, сброс возвращает начальное состояние. Поле поиска —
только образец, что явно подписано. Второе поле намеренно показывает ошибку.
Раскрытие доставки содержит шаблон без обещаний владельцу/покупателю.

## Что предстоит следующим блокам

Каркас navigation/menu/drawer, настоящие товарные компоненты, сетка каталога,
поиск, серверные фильтры, галерея и корзина реализуются в своих блоках.
Для категорий принять контракт из [REFERENCE_AND_UX.md](REFERENCE_AND_UX.md);
дерево не хранить внутри React-компонента. Макеты и SKU-значения библиотеки
не переносить в реальный каталог или базу.

`DenimStudy` — собственная декоративная векторная иллюстрация, aria-hidden.
Она показывает пропорцию образца; реальному товару потребуются фотографии
владельца и корректный alt. В проект не скопированы ассеты Spazio.
