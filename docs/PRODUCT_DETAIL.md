# Страница товара — блок 07

Маршрут `/product/[slug]`. Основной проверочный товар: `test-catalog-1`.
Источник — опубликованный Supabase-каталог, без статических массивов товаров.
Используются Manrope, токены, Price, Badge, Button, SizeSelector, Accordion
и существующая публичная оболочка KOS JEANS.

## Данные и права

`src/lib/product/data.ts` читает product, images, variants, product_categories
и публичные delivery_template/returns_template из store_settings. Клиент из
блока 06 stateless/publishable, без admin cookie и service-role ключа.
RLS исключает draft/archived/скрытых предков. Недопустимый/отсутствующий slug — 404.
Проверка выполняется до отправки основного HTML, без общего streaming loading,
который мог бы заменить HTTP 404 на 200. Есть маршрутная error boundary.

React cache объединяет повторные чтения в одном серверном запросе для metadata
и страницы. Это не межзапросный кеш: новый запрос заново читает базу (no-store,
force-dynamic). Изменение цены видно при обновлении страницы без деплоя.
Название/описание metadata берутся из товара, noindex/nofollow сохранены.
Product schema с фиктивными офферами не добавляется.

Галерея получает только UUID/alt фото. `/media/[id]` из блока 06 повторно проверяет
публичное чтение и отдаёт приватные файлы с no-store. Публичные URL Storage,
внешний кеш оптимизатора и привилегированный ключ не используются.

Похожие товары выбираются из реальных категорий текущего продукта, проходят тот
же RLS-каталог, исключают сам товар и повторения, ограничены четырьмя карточками.
Карточки каталога и рекомендаций теперь ведут на настоящий product-маршрут.

## Галерея и адаптивность

Слева на desktop — главный кадр 3:4, снизу миниатюры и предыдущий/следующий кадр.
На mobile галерея находится перед информацией. Поддержаны кнопки, клавиатура
и горизонтальный swipe; вертикальное прокручивание не считается перелистыванием.

Увеличение открывает native dialog: увеличенный холст, прокрутка деталей,
переключение кадров, кнопка вписывания в окно. Фото для zoom загружается только
при открытии. Escape, focus trap, возврат фокуса и блокировка фона — общий Modal.
При отсутствии фотографий или ошибке загрузки показывается честное сообщение.

Браузерные проверки выполнены в Chrome на 320/390/768/1440 px, физический
телефон не использовался. [Размеры](previews/product/responsive.json),
[desktop](previews/product/desktop.jpg), [mobile](previews/product/mobile.jpg).

## Варианты и будущая корзина

`src/lib/product/variants.ts` — чистые функции вариантов и тип CartSelection.
Все активные размеры из данных показаны; доступность определяется текущим
цветом и stock > 0 у той же строки variant. Нулевые и отсутствующие сочетания
disabled. При смене цвета размер и количество сбрасываются; реальный UUID
появляется только после выбора существующего доступного варианта.

Показываются фактические остатки каждого размера выбранного цвета и SKU
выбранного варианта. Количество — целое от 1 до stock. CartSelection содержит
productId, variantId, size, color, quantity. Неверный продукт, inactive/zero-stock
вариант и недопустимое количество дают null.

«Додати в кошик» всегда disabled с явным пояснением. Нет записи localStorage,
изменения счётчика, оформления заказа или списания склада. В блоке 11 это будет
намерение клиента; серверная цена и доступность повторно проверяются в блоке 12.

Описание/материал/характеристики показываются из БД как текст. Условия доставки
и возврата читаются из публичных настроек; при отсутствии — редактируемое
пояснение о неподтверждённых условиях, без придуманных сроков и обещаний.

## Проверочные данные и команды

`npm run product:seed -- --dev-only` добавляет к существующему ТЕСТ-товару
три варианта (включая stock 0), два дополнительных изображения и явно тестовую
информацию о материале. Сценарий проверяет точное имя kos-jeans-dev и не
перезаписывает заполненные материал/характеристики. Изображения — лицензированные
иллюстрации из реестра блока 04, не фотографии настоящего ассортимента.
Ни production, ни реальные заказы не затрагиваются.

`npm run product:test:hosted -- --dev-only` проверяет прямой URL, поля из БД,
404 для закрытых/неизвестных товаров, точные варианты, три защищённых изображения,
категорию рекомендаций, отсутствие фото/вариантов, обновление цены без сборки.
Собственные временные цена и пустой продукт восстанавливаются/удаляются в finally.
Служебный ключ применяется только внутри dev-проверок в памяти процесса.
Отчёт: [block07-hosted.json](checks/block07-hosted.json).

`npm test` включает три регрессионных теста выбора вариантов/будущей корзины;
всего 24 локальных теста. CI не требует облачных ключей.

Владелец подтвердил, что env действуют для всех Vercel Preview; новой ветке
не нужны дополнительные значения. Production по-прежнему изолирован от dev.

## Референс

Публичная [карточка Spazio](https://spazio.ua/ua/zhenshchinam/odezhda/dzhinsy/dzhinsy_017146511_unisex/)
повторно просмотрена в Chrome: несколько кадров, размерный список с ограниченной
доступностью, SKU/состав/описание и рекомендации. Web-fetch вернул 403, но браузер
открыл страницу. Заимствованы только общие UX-паттерны, никаких чужих ассетов и текстов.
У KOS JEANS свои радиокнопки цвета/размера, галерея и визуальная система.

Технический источник: [Next metadata и request cache](https://nextjs.org/docs/app/api-reference/functions/generate-metadata).
