## Исправления и повторные проверки

- High optimizer bypass закрыт: HTTP 400 для product/category/banner/admin media;
  разрешённые изображения 160/480/960/1440 возвращают WebP с private/no-store.
  [HTTP-подтверждение](checks/quality/http-after.json). Старые версии Preview
  этого исправления не содержат; для дальнейшей приёмки использовать новую ветку.
- High checkout quota: IP → session → global; повторные отказы не исчерпывают
  общий лимит, число новых session rows ограничено лимитом IP. Проверены 230 повторов
  и 60 новых session identifiers. Миграция применена исключительно к dev.
- Medium: deferred order sum guard проверяет оба order_id; SQL тест отклоняет
  некорректный перенос строки и откатывает транзакцию.
- Medium: timeout 12 s на отдельную сетевую операцию каталога/Auth, сохранена отмена
  вызывающей стороны; ошибки сервера скрывают технические подробности.
  Ошибки проверки формы выделены в FormError; неизвестные Error.message не выходят в UI.
  Logout корректно сообщает о недоступности сервиса.
- Фото: действительное декодирование, предел 32 MP, EXIF удаляется при новой загрузке,
  нормализация в WebP; повреждённый файл с JPEG magic отклоняется. Приватный кеш
  оптимизатора не используется. Исходные фотографии существующего ассортимента не переписываются.
- Low: SVG favicon, nosniff, запрет iframe, Referrer-Policy. Canonical/description
  принудительно отправляются в первоначальном head без streaming metadata.
- Неудачная промежуточная проверка обнаружила регрессию от добавленного общего loading:
  streaming превращал 404 в HTTP 200. Общий loading удалён до публикации; прямые
  missing product и чужой receipt снова возвращают 404. Проверка не отключалась.

79 автоматических тестов, lint/typecheck и Webpack production build проходят.
`npm audit` — 0. [Клиентские артефакты](checks/quality/client-secrets.json):
73 файла, ~1.1 MB несжатого JS/JSON, приватных ключей/текущего server secret не найдено.
Это общий размер файлов сборки, не transfer одной страницы; Lighthouse отмечает

## Hosted-сценарии, повторно выполненные в блоке 15

- [Checkout](checks/quality/block12-hosted.json): ровно один заказ при повторе;
  приватный receipt; смена цены требует подтверждения; последние остатки при двух
  конкурентных транзакциях; полный rollback после частичного списания; RLS,
  недоступные варианты, архив, реальный HTTP 429/Retry-After. Собственные fixtures восстановлены.
- [Заказы](checks/quality/block13-hosted.json): две конкурентные отмены возвращают
  остаток один раз; разные конкурентные статусы отклоняют устаревшую запись;
  снимки не меняются с ценой, фильтры работают, прямые private URL и CSRF закрыты.
- [Товары](checks/quality/block10-hosted.json): anonymous/ordinary не меняют цену,
  размер и stock, не вызывают RPC, не загружают/удаляют фото и не видят черновики.
  Метаданные role=admin не дают полномочий. Только временный обычный пользователь удалён.
- [Корзина](checks/quality/block11-hosted.json): реальные варианты, цена сервера,
  shortage/zero stock, неизвестные и скрытые ID без раскрытия данных, невалидное
  количество/размер запроса отклоняются; ни заказа, ни списания от чтения корзины.
- [Контент](checks/quality/block14-hosted.json): черновое фото закрыто, изменения
  опубликованного контента без deploy, stale update и опасные ссылки отклоняются,
  тестовый контакт отражается в footer, затем точное исходное значение восстановлено.
- SQL-входы передаются параметрами RPC и проверяются на сервере; текст React экранируется,
  опасные URL/schemes исключены. Автоматические SQL/валидационные регрессии сохраняются.
- Cookies сессии: HttpOnly/SameSite=Lax, Secure на Vercel; роль читается из проверенной
  БД, не cookie/metadata. Истечение/отзыв/ошибки Auth fail closed проверены unit-тестами.
  Реальные UI-вход, выход, возобновление сессии и полный контрольный сценарий
  на новой Preview ещё ожидают административной сессии владельца.
