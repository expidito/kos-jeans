# Как управлять KOS JEANS

2026-11-26. Сейчас рабочие функции проверяются в **Preview → kos-jeans-dev**.
Production [kos-jeans.vercel.app](https://kos-jeans.vercel.app) безопасен, но не принимает
заказы и не предоставляет рабочую админку. Будущая рабочая база пока не создана.
Текущую Preview-ссылку берите в [PR блока16](https://github.com/expidito/kos-jeans/pulls)
по кнопке Preview у Vercel; может требоваться обычный вход в ваш Vercel.

## Вход и выход

Откройте Preview, добавьте `/admin/login`, введите свой email/пароль самостоятельно.
Не отправляйте пароль в чат. Публичной регистрации нет; аккаунт требует назначенной
роли. После работы нажмите «Вийти». После проверки блока15 сессия была завершена.
Если доступ потерян, используйте свой Supabase Dashboard и обратитесь к Codex;
готового пользовательского экрана восстановления пароля в магазине пока нет.
Процедура первого администратора рабочей базы — в [инструкции](SUPABASE_PRODUCTION.md).

## Категории

«Категорії» → «Додати категорію»: название, slug, родитель, порядок, описание,
разрешённое фото, «Показувати в магазині» → «Зберегти». Например, дочерняя категория
внутри «Жінкам» появится в меню после сохранения, если её родители тоже открыты.
Скрытие/архив убирает раздел, не удаляя товары. Архив требует подтверждения.
[Подробности](ADMIN_CATEGORIES.md).

## Товар и фотографии

«Додати товар»: название, уникальные SKU/slug, описание/состав/характеристики,
категория, цена и при необходимости большая старая цена. Добавьте разрешённые
фото JPEG/PNG/WebP до3МБ каждое, до10: обложка, стрелки порядка, alt, замена/удаление.
Удаление сохранённого фото нужно подтвердить и затем сохранить товар.

Для каждого сочетания размера/цвета укажите **отдельный stock**. Можно добавить
свои цифровые/буквенные размеры. Нулевой размер недоступен покупателю; не вводите
выдуманный stock. Сначала «Зберегти чернетку», проверьте, затем статус «Опубліковано»
и «Зберегти». Для публикации нужны описание, фото, активные варианты и открытая категория.
Цена и остатки обновляются без Git/deploy в подключённом окружении.
[Полная инструкция](ADMIN_PRODUCTS.md).

Если открыты две вкладки и получен конфликт/ошибка сохранения, обновите страницу,
сверьте чужие изменения и повторите своё. Не перезаписывайте наугад. Если сеть
прервалась, сначала проверьте, что уже сохранилось.

## Заказы

«Замовлення» → поиск/фильтр → номер заказа: проверьте покупателя, доставку и
снимки вариантов/цен. Изменение статуса требует подтверждения. Скасування возвращает
stock только один раз; отменённый заказ не восстанавливается простым переключением статуса.
Не отправляйте TEST-заказы покупателю. Заказная сумма — снимок на момент покупки,
она не меняется при новой цене товара. [Подробности](ADMIN_ORDERS.md).

## Баннеры и информация

«Банери» → новый приватный черновик → фото, заголовок, alt, кнопка и существующая
страница назначения → видимость/даты → сохранить. Дождитесь завершения загрузки;
затем проверяйте главную после reload. Скрытие/архив не удаляет историю и старые файлы.

«Налаштування» содержит контакты, соцсети и информационные тексты. Сохраняйте секции
по одной, дожидаясь сообщения об успехе. Подтверждайте только проверенные контакты.
Юридические страницы остаются черновиками до согласования; HTML-теги отображаются
обычным текстом. Не вставляйте ключи/пароли/приватные сведения.
[Контент и SEO](CONTENT_AND_SEO.md).

## Что меняется без программирования

Товары, размеры, stock, цены, фото, категории, баннеры и тексты — через админку.
Дизайн/поведение приложения — через Codex, feature PR, проверки и ваше разрешение merge.
Изменение товаров в dev не меняет Production. Для настоящих продаж сначала выполнить
[LAUNCH_CHECKLIST.md](LAUNCH_CHECKLIST.md); обходить отключённый checkout нельзя.
