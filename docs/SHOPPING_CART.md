# Корзина — блок 11

`/cart` доступен без регистрации. Кнопка добавления на странице товара работает
после выбора существующего активного размера/цвета с остатком. Повторный вариант
увеличивает одну позицию; разные UUID вариантов остаются разными позициями.

## Сохранение и актуальность

- localStorage `kos-jeans-cart-v1`: версия формата 1, массив `{variantId, quantity}`.
  Названия, цены, фото и остатки не сохраняются и не принимаются как достоверные.
- До 50 позиций, количество от 1 до 99. Удаление — отдельное действие.
- Сохранение действует на текущем origin браузера; разные Preview-домены имеют
  разные корзины. Синхронизации между устройствами/аккаунтами в этой версии нет.
- `useSyncExternalStore` обеспечивает одинаковый серверный/первый клиентский HTML,
  обновление шапки и синхронизацию вкладок через `storage`. При запрете хранилища
  работает память вкладки и показывается предупреждение о невозможности сохранения.
- Перед каждым добавлением сервер читает актуальный вариант. Асинхронные добавления
  последовательно обрабатываются, объединение проверяет и уже выбранное количество.
- При открытии корзины, изменении количества, возвращении во вкладку и кнопке
  «Оновити ціни та залишки» выполняется новая сверка. Запросы не кэшируются;
  устаревшие ответы отменяются, ожидание ограничено 15 секундами.
- При нехватке выбранное количество сохраняется с предупреждением и явной кнопкой
  коррекции до остатка. Позиция с нулевым остатком/закрытым товаром недоступна и
  исключается из суммы. Закрытые и несуществующие варианты не раскрывают метаданные.
- Суммы считаются целыми копейками. Это информационная стоимость корзины:
  итог заказа в будущем обязан независимо пересчитываться сервером блока 12.

## Сервер и безопасность

`POST /api/cart` — только чтение. Принимает ограниченный JSON до 12 КБ, проверяет
UUID, целые количества, число позиций и дубликаты. Произвольные поля цены/названия
игнорируются. Анонимный stateless клиент с publishable key читает `product_variants`
с inner join `products` и разрешённые `product_images`; RLS определяет доступность.
Сессия администратора не используется для публичного чтения.

Ответы private/no-store/noindex. Обложки идут через существующий защищённый
`/media/[id]`. service-role, SQL записи, заказы, резерв и списание отсутствуют.
Оформление явно отключено. Production по-прежнему изолирован от kos-jeans-dev;
его переменные Vercel не менялись.

Сбой сети не очищает выбранные ID; показывается повторная попытка. Повреждённый
или неизвестный формат localStorage безопасно открывается как пустая корзина.
Данные из localStorage, даже валидные UUID, проходят повторную RLS-проверку.

## Проверки и приёмка

`npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.
`npm run cart:test:hosted -- --dev-only` использует только kos-jeans-dev и локальную
сборку на 3011; `CART_TEST_BASE` выбирает другой доступный адрес. Скрипт не меняет
товары, остатки или заказы. Внешний Preview защищён Vercel; его UI проверяется в
браузере с обычной Vercel-сессией, без отключения Deployment Protection.

Через Preview проверены Wide Leg Blue: 26 × 1, 27 × 2, две позиции, счётчик 3,
3897 ₴; изменение количества с клавиатуры, reload и закрытие/новое открытие вкладки,
объединение того же варианта, удаление и полная очистка. Полное закрытие всего
пользовательского браузера не выполнялось; постоянство обеспечивается localStorage.

Через существующую авторизованную админку блока 10 (та же kos-jeans-dev) временно
изменены цена 1299 → 1399 ₴ и остаток 27: 5 → 1. Без deploy корзина показала
4197 ₴ и нехватку, кнопка коррекции уменьшила количество. После теста через форму
восстановлены 1299 ₴ и stock=5; SQL-проверка подтвердила также все прочие остатки,
пять фото и публикацию. Никакие товары/категории/файлы не удалялись.

Отчёты: `docs/checks/block11-{hosted,ui,restored,production}.json`.
Responsive 320/390/768/1440 и снимки: `docs/previews/cart/`.
